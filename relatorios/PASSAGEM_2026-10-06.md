- **Antes de rodar algo na GPU: `git pull` + reiniciar o kernel do notebook** e
  conferir a versão (`VERSAO_EXTRACAO` / sha do prompt). Em 06/10 uma rodada
  inteira saiu com o código antigo.
- **Rodar scripts pelo Python do WSL** (`.venv/bin/python`). No Windows, o
  Controle Inteligente de Aplicativos bloqueia DLLs do scikit-learn — não
  desligar (não volta sem reset). Pelo PowerShell:
  `wsl.exe -d ubuntu-24.04 -- bash <script.sh>` (passar comandos inline pelo
  Git Bash embaralha aspas; usar arquivo .sh).
- Git no caminho UNC precisa de `git -c safe.directory=*`; via `wsl.exe` não.
- Strings com `\n` dentro de f-string geradas via heredoc do Git Bash viram
  quebra de linha real — gerar código de notebook por arquivo .py.
- O usuário prefere **acompanhar execuções no terminal dele**: escrever o script,
  commitar com previsões, e deixar ele rodar e colar a saída.
